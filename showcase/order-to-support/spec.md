# Showcase Template: E-commerce Order → Support Flow

**Category:** E-commerce / support · **Status:** Idea

## Pitch
Orders and customer questions connect automatically: exceptions are flagged before customers complain, and routine "where's my order?" tickets are triaged or drafted for you.

## Flow (draft)
New/updated order → exception checks (delay, address issue, high value) → create/update helpdesk contact → notify team on exceptions → proactive customer update; in parallel: new ticket → LLM classifies intent/urgency → route + draft reply for approval.

## Guardrails
Verify identity before sharing order data, approval gate for refunds, review path for angry/legal/refund tickets, duplicate-order guard.

## Typical apps
Shopify (or similar), helpdesk or Gmail, Slack, Claude/OpenAI, data table.

## Open decisions for design
Which store/helpdesk to demo, exception rules, reply tone guide.
